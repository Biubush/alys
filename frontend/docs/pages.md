# 阿里云盘同步系统前端页面说明文档

## 项目概述

本项目是阿里云盘同步工具的Web前端界面，基于React、TypeScript和Ant Design构建。该系统允许用户登录阿里云盘，创建自动同步任务，监控任务执行情况，并提供管理员功能来管理用户和系统设置。

## 技术栈

- **框架**: React 18
- **语言**: TypeScript 4
- **状态管理**: Redux Toolkit
- **UI组件库**: Ant Design 5
- **路由**: React Router 6
- **HTTP请求**: Axios
- **构建工具**: Vite 4
- **样式**: SASS

## 页面结构

前端应用分为三个主要部分：

1. **认证页面** - 包括登录、注册、找回密码等
2. **用户页面** - 普通用户可访问的功能
3. **管理员页面** - 仅管理员可访问的系统管理功能

### 布局组件

- **AuthLayout** - 认证页面的布局，简洁居中设计
- **UserLayout** - 用户页面的布局，包含侧边导航和顶部栏
- **AdminLayout** - 管理员页面的布局，采用深色主题，包含侧边导航和顶部栏

## 功能模块

### 1. 认证模块

- **登录** - 用户名/密码登录系统
- **注册** - 新用户注册，需要邮箱验证
- **找回密码** - 通过邮箱验证码重置密码
- **重设密码** - 设置新密码

### 2. 用户模块

- **个人中心** - 查看和修改个人资料
- **阿里云盘登录** - 连接阿里云盘账号
- **日志查看** - 查看个人操作日志

### 3. 任务模块

- **任务列表** - 查看所有创建的同步任务
- **任务详情** - 查看单个任务的详细信息和执行记录
- **创建任务** - 创建新的同步任务
- **编辑任务** - 修改现有任务的设置

### 4. 管理员模块

- **系统概览** - 查看系统整体情况
- **用户管理** - 管理所有用户账号
- **任务管理** - 管理系统中所有任务
- **系统日志** - 查看全局操作日志
- **系统设置** - 配置系统参数

## 路由系统

```
/
├── auth/
│   ├── login             # 登录页面
│   ├── register          # 注册页面
│   ├── forgot-password   # 忘记密码页面
│   └── reset-password    # 重置密码页面
├── dashboard             # 用户仪表盘
├── profile               # 个人资料
├── aliyun-login          # 阿里云盘登录
├── tasks/                # 任务相关页面
│   ├── <empty>           # 任务列表
│   ├── create            # 创建任务
│   ├── :id               # 任务详情
│   └── :id/edit          # 编辑任务
├── logs                  # 用户日志
└── admin/                # 管理员页面
    ├── dashboard         # 管理员仪表盘
    ├── users/            # 用户管理
    │   ├── <empty>       # 用户列表
    │   └── :id           # 用户详情
    ├── tasks/            # 任务管理
    │   ├── <empty>       # 全部任务列表
    │   └── :id           # 任务详情
    ├── logs              # 系统日志
    └── settings          # 系统设置
```

## 详细页面说明

### 认证页面

#### 登录页 (`/auth/login`)

- **功能**: 用户登录系统
- **组件**:
  - 登录表单（用户名/密码）
  - 记住我选项
  - 忘记密码链接
  - 注册账号链接

- **功能**: 新用户注册
- **组件**:

- **状态**: 注册状态、验证码发送状态、加载状态、错误信息

- **功能**: 请求密码重置
- **组件**:
  - 邮箱输入表单
  - 发送验证码按钮
  - 验证码输入框
- **状态**: 验证码发送状态、验证状态、加载状态、错误信息

#### 重置密码页 (`/auth/reset-password`)

- **功能**: 设置新密码
- **组件**:
  - 新密码输入框
  - 确认密码输入框
  - 提交按钮
- **状态**: 重置状态、加载状态、错误信息

## 状态管理

使用Redux Toolkit管理状态，主要包含以下几个状态切片：

1. **authSlice** - 管理认证状态、用户信息和认证相关操作
2. **userSlice** - 管理用户资料、阿里云盘登录状态和用户日志
3. **taskSlice** - 管理任务列表、任务详情和任务操作
4. **adminSlice** - 管理管理员相关的状态数据

## 接口交互

所有与后端的交互通过Axios实现，主要分为以下几个API模块：

1. **authApi** - 处理认证相关请求
2. **userApi** - 处理用户信息相关请求
3. **taskApi** - 处理任务相关请求
4. **adminApi** - 处理管理员功能相关请求

## 响应式设计

- 桌面优先设计
- 支持平板电脑适配
- 关键功能支持移动设备

## 常见问题

1. **如何添加新页面？**
   - 在对应目录下创建页面组件
   - 在`routes/index.tsx`中添加路由配置
   - 如需状态管理，在相应的状态切片中添加

2. **如何添加新功能？**
   - 在`api`目录下添加相应的API调用方法
   - 在状态切片中添加相应的异步操作和reducer
   - 在页面组件中使用Redux hooks获取数据

3. **如何处理权限控制？**
   - 使用路由守卫组件控制页面访问权限
   - 在组件级别使用条件渲染控制功能展示
