## 管理员账户

### 初始管理员设置

系统初始化时会创建一个默认管理员账户，初始密码在安装过程中设置。首次登录后，请立即修改默认密码以确保安全。

如果您是通过Docker部署，初始管理员信息在`config.ini`文件中配置：

```ini
[ADMIN]
init_admin_username = admin
init_admin_password = your_secure_password
init_admin_email = admin@example.com
```

### 管理员登录

1. 访问系统登录页面，输入管理员用户名和密码。
2. 登录成功后，系统会自动识别您的管理员身份，显示管理员导航菜单。
3. 点击顶部导航栏的"管理后台"按钮进入管理界面。

### 修改管理员密码

1. 在管理后台，点击右上角的用户头像，选择"个人设置"。
2. 点击"修改密码"按钮。
3. 输入当前密码和新密码（两次）。
4. 点击"确认修改"保存更改。

### 添加新管理员

1. 在管理后台，导航至"用户管理"页面。
2. 点击"添加管理员"按钮。
3. 填写新管理员信息：
   - 用户名
   - 电子邮箱
   - 初始密码
   - 管理权限级别（可选）
4. 点击"创建"按钮完成添加。

> **安全提示**：请谨慎添加管理员账户，并确保选择可信任的人员。管理员具有对系统的完全控制权。

## 管理员仪表盘

### 系统概览

管理员仪表盘提供系统整体情况的直观视图，包含以下信息：

- 用户总数和活跃用户数
- 任务总数和活跃任务数
- 今日执行任务数和成功率
- 系统资源使用情况
- 最近系统事件
- 服务状态指示器

### 关键指标监控

仪表盘上的关键指标卡片显示：

1. **用户指标**
   - 今日新增用户数
   - 活跃用户比例
   - 用户增长趋势图

2. **任务指标**
   - 今日执行任务数
   - 任务成功率
   - 任务执行趋势图

3. **系统指标**
   - CPU使用率
   - 内存使用率
   - 存储空间使用情况
   - 请求响应时间

### 系统状态检查

系统状态面板显示各组件的运行状态：

- Web服务器
- 数据库服务
- Redis服务
- 任务队列
- 邮件服务
- 阿里云盘API连接

点击"运行诊断"按钮可执行系统健康检查，自动检测并报告潜在问题。

## 用户管理

### 查看用户列表

1. 在管理后台侧边栏，点击"用户管理"。
2. 系统显示所有用户列表，包括以下信息：
   - 用户ID
   - 用户名
   - 电子邮箱
   - 注册时间
   - 上次登录时间
   - 状态（活跃/禁用）
   - 任务数量
   - 操作按钮

用户列表支持多种筛选和排序方式：
- 按状态筛选（全部/活跃/禁用）
- 按注册时间排序
- 按活跃度排序
- 关键词搜索（用户名/邮箱）

### 用户详情查看

1. 在用户列表中，点击用户名或"查看详情"按钮。
2. 系统显示用户的详细信息，包括：
   - 基本信息（用户名、邮箱、注册时间等）
   - 账号统计（任务数、执行次数、成功率等）
   - 阿里云盘绑定状态
   - 操作日志
   - 任务列表

### 用户状态管理

管理员可以启用或禁用用户账号：

1. 在用户列表中，找到目标用户。
2. 点击"状态"列的开关按钮，或使用"操作"下拉菜单中的"启用/禁用"选项。
3. 在确认对话框中，可以选择是否通知用户，并添加备注说明原因。
4. 点击"确认"完成操作。

被禁用的用户将无法登录系统，其任务也会自动暂停执行。

### 重置用户密码

1. 在用户详情页面或用户列表的"操作"菜单中，选择"重置密码"。
2. 选择重置方式：
   - 系统生成随机密码并发送到用户邮箱
   - 管理员手动设置新密码
3. 点击"确认"完成重置。

> **注意**：重置密码应当在用户无法正常登录并提出申请的情况下使用。

### 用户限制设置

管理员可以为单个用户或全局设置限制：

1. 在"系统设置"下的"用户限制"选项卡：
   - 设置每个用户可创建的最大任务数
   - 设置单个用户的任务并发执行数
   - 配置敏感操作的频率限制

2. 在用户详情页面，可设置特定用户的自定义限制：
   - 点击"设置限制"按钮
   - 配置该用户的特殊限制（优先级高于全局设置）
   - 点击"保存"应用设置

## 任务管理

### 全局任务概览

1. 在管理后台侧边栏，点击"任务管理"。
2. 系统显示全局任务列表，包括所有用户创建的任务：
   - 任务ID
   - 任务名称
   - 创建者
   - 创建时间
   - 上次执行时间
   - 下次执行时间
   - 状态（启用/禁用）
   - 成功率
   - 操作按钮

任务列表支持多种筛选和排序：
- 按状态筛选（全部/启用/禁用）
- 按创建时间排序
- 按执行频率排序
- 按成功率排序
- 按用户筛选
- 关键词搜索

### 任务详情查看

1. 在任务列表中，点击任务名称或"查看详情"按钮。
2. 系统显示任务的详细信息，包括：
   - 基本信息（名称、创建者、创建时间等）
   - 配置信息（分享链接、目标文件夹、定时规则等）
   - 执行统计（总执行次数、成功次数、失败次数等）
   - 执行记录列表

### 任务状态控制

管理员可以控制任何任务的状态：

1. 在任务列表中，找到目标任务。
2. 点击"状态"列的开关按钮，或使用"操作"下拉菜单中的"启用/禁用"选项。
3. 在确认对话框中，可以选择是否通知任务创建者，并添加备注说明原因。
4. 点击"确认"完成操作。

### 手动触发任务

管理员可以手动触发任何任务的执行：

1. 在任务列表或任务详情页面，点击"立即执行"按钮。
2. 系统将任务加入执行队列，并显示执行进度。
3. 执行完成后，可以在执行记录中查看结果。

### 任务执行记录

1. 在管理后台侧边栏，点击"执行记录"。
2. 系统显示全局执行记录列表，包括所有任务的执行历史：
   - 执行ID
   - 任务名称
   - 创建者
   - 执行时间
   - 执行状态
   - 执行时长
   - 同步文件数量
   - 操作按钮

3. 点击"查看详情"可以查看单次执行的详细信息。

## 系统日志

### 操作日志查看

1. 在管理后台侧边栏，点击"系统日志"，然后选择"操作日志"选项卡。
2. 系统显示所有用户的操作记录，包括：
   - 时间戳
   - 用户
   - 操作类型
   - 操作详情
   - IP地址
   - 浏览器信息

### 系统事件日志

1. 在"系统日志"页面，选择"系统事件"选项卡。
2. 系统显示所有系统级别事件，包括：
   - 时间戳
   - 事件类型
   - 事件级别（信息、警告、错误）
   - 事件详情
   - 相关组件

### 错误日志分析

1. 在"系统日志"页面，选择"错误日志"选项卡。
2. 系统显示所有错误和异常记录，包括：
   - 时间戳
   - 错误级别
   - 错误类型
   - 错误消息
   - 堆栈跟踪（可展开查看）
   - 上下文信息

错误日志页面提供了问题分析工具：
- 趋势图显示错误发生频率
- 错误类型分布图
- 常见错误摘要
- 相关性分析

### 日志筛选与导出

所有日志页面提供高级筛选功能：

1. 时间范围选择
2. 级别筛选
3. 类型筛选
4. 用户筛选
5. 关键词搜索

日志导出功能：
1. 点击"导出日志"按钮
2. 选择导出格式（CSV、JSON或Excel）
3. 选择是否应用当前筛选条件
4. 点击"确认"开始下载

## 系统设置

### 基本设置

在"系统设置"页面的"基本设置"选项卡，可以配置：

1. **系统信息**
   - 系统名称
   - 系统描述
   - 管理员联系邮箱

2. **界面设置**
   - 系统Logo
   - 网站图标
   - 默认语言
   - 是否显示版本号

3. **注册设置**
   - 是否开放注册
   - 是否需要邮箱验证
   - 注册验证码有效期

### 邮件服务配置

在"邮件设置"选项卡，配置系统发送邮件的服务：

1. **SMTP服务器**
   - SMTP主机地址
   - SMTP端口
   - 是否使用SSL/TLS
   - 认证用户名和密码

2. **邮件模板**
   - 注册验证邮件
   - 密码重置邮件
   - 通知邮件
   - 系统警报邮件

3. **测试功能**
   - 测试邮件发送按钮
   - 测试结果显示

### 任务执行配置

在"任务设置"选项卡，配置任务执行相关参数：

1. **全局限制**
   - 系统最大并发任务数
   - 单个任务最大执行时间
   - 默认重试次数和间隔

2. **定时设置**
   - 任务调度检查间隔
   - 是否允许用户使用高频率Cron表达式
   - Cron表达式最小间隔限制

3. **文件同步设置**
   - 单次同步最大文件数
   - 单次同步最大总大小
   - 文件类型过滤规则

### 安全设置

在"安全设置"选项卡，配置系统安全相关参数：

1. **账号安全**
   - 密码复杂度要求
   - 登录失败锁定策略
   - 会话超时时间
   - 是否允许多设备同时登录

2. **API安全**
   - API访问速率限制
   - JWT令牌有效期
   - 刷新令牌有效期

3. **IP限制**
   - 是否启用IP白名单/黑名单
   - 配置受限IP列表
   - 异常登录地点检测

### 高级设置

在"高级设置"选项卡，配置系统高级参数：

1. **性能优化**
   - 缓存策略
   - 数据库连接池大小
   - 异步任务工作进程数

2. **阿里云盘API设置**
   - API请求超时时间
   - 请求间隔限制
   - 批量操作大小限制

3. **日志设置**
   - 日志级别
   - 日志保留天数
   - 是否记录详细请求信息

## 故障排除

### 常见问题解决

本节列出管理员可能遇到的常见问题及解决方法：

1. **用户无法登录**
   - 检查用户账号状态是否被禁用
   - 验证用户凭据是否正确
   - 检查IP是否被限制

2. **任务执行失败**
   - 检查阿里云盘API状态
   - 验证分享链接有效性
   - 检查目标文件夹权限
   - 确认系统资源是否充足

3. **邮件发送失败**
   - 验证SMTP配置
   - 检查邮件服务器连接
   - 确认发件地址未被列入黑名单

4. **系统性能下降**
   - 检查数据库性能
   - 监控服务器资源使用
   - 优化任务调度
   - 清理过期数据和缓存

### 性能优化

针对系统性能问题的优化建议：

1. **数据库优化**
   - 定期执行索引优化
   - 清理无用数据
   - 调整查询缓存大小

2. **应用服务器优化**
   - 增加工作进程数
   - 调整内存分配
   - 优化静态资源缓存

3. **任务调度优化**
   - 错开任务执行时间
   - 增加Celery工作节点
   - 调整任务队列配置

### 错误处理

处理系统错误的步骤：

1. **识别错误**
   - 查阅错误日志
   - 分析错误模式和频率
   - 确定影响范围

2. **隔离问题**
   - 确定是单个用户还是全局问题
   - 确定是特定功能还是系统级问题
   - 测试环境复现问题

3. **临时解决方案**
   - 重启服务
   - 清除缓存
   - 限制问题功能
   - 通知用户

4. **永久修复**
   - 应用系统更新
   - 修改配置参数
   - 优化代码逻辑
   - 完善错误处理
