# ALYS-Pro 项目简介

[返回文档首页](./README.md)

## 项目概述

ALYS-Pro（阿里云盘同步系统）是一个专为阿里云盘用户设计的文件同步和管理系统。该系统提供了高效的文件同步、自动备份、文件共享和管理功能，帮助用户更好地利用阿里云盘服务。

## 主要功能

- **文件自动同步**：实现本地文件与阿里云盘的自动双向同步
- **定时备份**：支持定时备份功能，确保数据安全
- **同步任务管理**：灵活的同步任务创建、编辑、暂停和恢复功能
- **用户认证**：安全的账户管理和阿里云盘授权流程
- **文件操作**：上传、下载、删除和预览云盘文件
- **状态监控**：同步状态实时监控与历史记录查询
- **多用户支持**：支持多用户独立配置和使用

## 技术架构

ALYS-Pro采用前后端分离的现代化架构设计：

### 后端架构

- **开发框架**：FastAPI (Python)
- **数据存储**：文件系统与本地数据库
- **主要模块**：
  - 认证服务
  - 用户管理
  - 任务调度
  - 文件同步
  - 阿里云盘API集成

### 前端架构

- **开发框架**：React + TypeScript
- **UI组件库**：Ant Design
- **状态管理**：Redux Toolkit
- **主要功能模块**：
  - 用户界面
  - 文件浏览器
  - 任务管理界面
  - 系统设置
  - 状态监控与日志查看

### 部署方式

系统支持多种部署方式：

- Docker容器化部署
- 传统服务器部署
- 开发环境部署

更多详细信息请参考[部署指南](./deployment-guide.md)。
